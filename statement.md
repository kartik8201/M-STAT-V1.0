# M-STAT V1.0

## Problem Statement

When a computer starts running slowly or the internet connection becomes unstable, it can be difficult to figure out what is causing the problem. Usually, users have to open different Windows tools to check CPU usage, memory, running processes, and network conditions. M-STAT brings these basic checks together in one simple terminal-based application.

## Scope

M-STAT is designed to provide a quick overview of a computer's system and network condition. It can monitor CPU, RAM, and storage usage, check running processes, display network information, test internet speed, and perform a basic diagnostic of the system.

## Target Users

- Students who want to understand or troubleshoot their computer
- Home computer users
- Users who need a simple way to check basic system and network problems

## High-Level Features

- Quick system and network diagnostic
- CPU, RAM, and storage monitoring
- Top process monitoring
- Network information and connectivity checks
- Internet download and upload speed testing
- System health analysis
- Live system monitoring
